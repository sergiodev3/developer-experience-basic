# git-practica (ejemplo genérico)

Repositorio de práctica para el ejercicio 0.2 — Git y GitHub.

## Sobre mí

Contenido genérico de ejemplo. Aquí cada alumno escribe una línea corta
sobre sí mismo — esta es la línea que, en la Parte B, dos personas van
a editar a propósito para provocar un conflicto de Git.

## Qué contiene este proyecto

- `src/index.js` — función de ejemplo genérica.
- `notas.md` — notas de aprendizaje del bloque 0.1.
- `.gitignore` — protege `node_modules/` y `.env` desde el primer commit.
