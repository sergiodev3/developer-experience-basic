# Notas — Bloque 0.1 (ejemplo genérico)

Contenido genérico de ejemplo, para tener un archivo más que commitear
durante la Parte A del ejercicio 0.2.

- La terminal siempre te dice dónde estás parado: revisa el prompt.
- `..` sube un nivel, `.` es la carpeta actual, `~` es tu carpeta de usuario.
- Una ruta relativa funciona en cualquier computadora del equipo; una
  ruta absoluta no.
